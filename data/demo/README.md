# Synthetic demo fixtures

All CSV and JSONL records in this directory are deterministic synthetic fixtures. District labels are illustrative, and values do not represent measured Indian yields, weather, vegetation, or official advisories. Use these files only to exercise the code and interface.

`metadata.json` records the seed, row counts, year ranges, and non-operational warning. Run `crop-risk demo` to regenerate the fixtures and the corresponding local artifacts under `data/processed/`.
